## Deviations (deliberate, authenticity-mandated)

1. **04-place-of-care full-bleed**: the ref's facility photo is a generated COMPOSITE
   (reception desk + seating row in one room) that matches no supplied original. The
   manifest forbids fabricating Sigma Core spaces. Build maps the canvas to authentic
   `reception-1.png` + inset `waiting-room.png` (region 1b). Do not inpaint or extend
   facility pixels.
2. **08 banner strip**: use authentic `waiting-room.png` letterboxed; the ref band's
   slight rightward extension is not reproduced.
3. **Logo**: design refs render a placeholder/approximation; build always mounts
   `shared/logo.png` as-is (mark + lettering separately legible; never re-set in type).

## Key CODE techniques (full recipes in the plan)

- Field system: ink `#101E33` / surface `#F7F6F3` bands per section_manifest
  background_progression; seams share identical edge colors.
- `core-horizon` motif: single flat electric `#0877BE` rule, 3-4px, crossing the
  01→02 navy seam once, then resolving. Never a ribbon/wave/nerve.
- 02 circular mask: `border-radius:50%`/`clip-path:circle()` container over the
  rectangular photo + 2px silver `#C7CBD0` partial arc (CSS, not baked).
- 05 `measured-journey-rule`: continuous 3px ink rule linking three unnumbered step
  columns, ~34px electric cap; vertical with three stops on mobile. NO numerals
  (customer hard rule).
- 06 booking panel: photo full-bleed in panel; ink-to-transparent gradient wash +
  copy + CTA are live layers (the shipped photo is clean underneath).
- CTAs: action `#0666A5` fill, hover `#054F80`, focus ring `#72C7F3`, lucide arrows;
  secondary = 1px light/60 border ghost.
- Playfair Display 600 = display role only; Source Sans 3 400/600 = everything else
  (fonts supplied in design_refs/fonts).

## Compliance guardrails carried into assets

Generated people are anonymous and never patients/providers/staff/testimonials/proof.
Facility depicted only by supplied originals. No numerals-as-decoration, no invented
credentials/ratings. Guide pages in `lifestyle-reading-guide.jpg` are plain (no
legible words/logos).
